Title: FastGraph: A Fast Distributed Graph Clustering Algorithm

Authors: Anonymous Authors (Under Review)

Abstract:
Graph clustering is an essential primitive in network analysis, bioinformatics, and recommendation engines. Modern massive graphs contain billions of edges, rendering classical spectral algorithms computationally intractable. In this paper, we describe FastGraph, a distributed heuristic graph partitioning algorithm designed for scale.

1. Introduction
Spectral clustering computes eigenvectors of graph Laplacian matrices, running in cubic time complexity O(N^3). Even randomized approximations require significant distributed memory communication. We address this challenge with a lightweight local edge-swapping heuristic.

2. Algorithm Overview
FastGraph operates iteratively over graph partitions. In each super-step, nodes inspect neighboring cluster assignments and compute a local modularity gain metric Delta Q. If Delta Q > 0, the node migrates to the candidate cluster. Edge cuts are synchronized using MPI collective communications every 5 iterations.

3. Preliminary Findings
On synthetic Erdős-Rényi random graphs with 10 million vertices, FastGraph converges in 14 iterations, producing an approximate modularity score of 0.62. Runtime was observed to scale linearly with the number of worker compute nodes.

4. Conclusion
FastGraph offers an intuitive and scalable distributed approach for massive graph partitioning.
